Mateusz Sadowski - projekt zaliczeniowy

PLAN PROJEKTU:

1. Aplikacja trójwarstwowa z backendem w ASP.NET Core 8, frontendem w React + Typescript oraz bazą danych w MySQL.
2. Projekt ma być aplikacją webową będącą serwisem z przepisami na drinki, gdzie można dodawać swoje przepisy, wyszukiwać obecne oraz oceniać lub pisać komentarze.
3. Plan projektu jest ambitny - mam zamiar zaimplementować kilka wzorców projektowych oraz unit testy, jednak zobaczymy jak wyjdzie w praktyce.
